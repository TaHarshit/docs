This guide walks you through everything you need to make your first successful API call. By the end, you will have a Bearer token, a verified profile request, and your first client record — all from the command line or your language of choice.

## Prerequisites

Before you begin, make sure you have:

- An account at [dashboard.fss-measurement.com](https://dashboard.fss-measurement.com)
- An active subscription plan (required for protected endpoints)
- `curl` or an HTTP client installed

<Note>
  If you do not yet have an account, complete step 1 below before proceeding to sign in.
</Note>

## Steps

<Steps>
  <Step title="Sign up for an account">
    Create your account by sending a `POST` request to `/user/signup`. Every request — including public ones — must include the static `api-key` and `platform` headers.

    ```bash
    curl --location 'https://fssportal.com/api/v1/user/signup' \
    --header 'platform: WEB' \
    --header 'api-key: FSS2023' \
    --header 'Content-Type: application/json' \
    --header 'Accept: application/json' \
    --data-raw '{
        "name": "Your Name",
        "email": "your-email@example.com",
        "password": "your-password"
    }'
    ```

    A successful response confirms account creation. You can then sign in to receive your Bearer token.
  </Step>

  <Step title="Sign in to get a Bearer token">
    Call `/user/signin` with your email and password. The response contains the `api_token` field you will use in all subsequent requests.

    <CodeGroup>

    ```bash cURL
    curl --location 'http://fssportal.com/api/v1/user/signin' \
    --header 'platform: WEB' \
    --header 'api-key: FSS2023' \
    --header 'Content-Type: application/json' \
    --header 'Accept: application/json' \
    --data-raw '{
        "email": "your-email@example.com",
        "password": "your-password",
        "device_token": "",
        "platform": "WEB"
    }'
    ```

    ```javascript JavaScript
    const FSS_API_URL = 'http://fssportal.com/api/v1';
    const API_KEY = 'FSS2023';

    async function signIn(email, password) {
      const response = await fetch(`${FSS_API_URL}/user/signin`, {
        method: 'POST',
        headers: {
          'platform': 'WEB',
          'api-key': API_KEY,
          'Content-Type': 'application/json',
          'Accept': 'application/json'
        },
        body: JSON.stringify({
          email,
          password,
          device_token: '',
          platform: 'WEB'
        })
      });

      const data = await response.json();
      return data.data.api_token;
    }
    ```

    ```python Python
    import requests

    FSS_API_URL = 'http://fssportal.com/api/v1'
    API_KEY = 'FSS2023'

    def sign_in(email, password):
        response = requests.post(
            f'{FSS_API_URL}/user/signin',
            headers={
                'platform': 'WEB',
                'api-key': API_KEY,
                'Content-Type': 'application/json',
                'Accept': 'application/json'
            },
            json={
                'email': email,
                'password': password,
                'device_token': '',
                'platform': 'WEB'
            }
        )

        data = response.json()
        return data['data']['api_token']
    ```

    ```php PHP
    <?php

    $fssApiUrl = 'http://fssportal.com/api/v1';
    $apiKey = 'FSS2023';

    function signIn($email, $password) {
        global $fssApiUrl, $apiKey;

        $ch = curl_init($fssApiUrl . '/user/signin');

        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_POST, true);
        curl_setopt($ch, CURLOPT_HTTPHEADER, [
            'platform: WEB',
            'api-key: ' . $apiKey,
            'Content-Type: application/json',
            'Accept: application/json'
        ]);
        curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
            'email' => $email,
            'password' => $password,
            'device_token' => '',
            'platform' => 'WEB'
        ]));

        $response = curl_exec($ch);
        curl_close($ch);

        $data = json_decode($response, true);
        return $data['data']['api_token'];
    }
    ```

    </CodeGroup>

    A successful sign-in returns your Bearer token inside `data.api_token`:

    ```json
    {
      "message": "Login successful",
      "data": {
        "api_token": "your-bearer-token-here",
        "user": {
          "id": 1,
          "name": "Your Name",
          "email": "your-email@example.com"
        }
      }
    }
    ```

    <Warning>
      Store `api_token` securely. Do not log it or commit it to version control. Treat it like a password.
    </Warning>
  </Step>

  <Step title="Make your first authenticated request">
    Use the token from the previous step to fetch your profile. Pass it as a Bearer token in the `Authorization` header.

    ```bash
    curl --location 'https://fssportal.com/api/v1/user/get_profile' \
    --header 'platform: WEB' \
    --header 'api-key: FSS2023' \
    --header 'Authorization: Bearer your-bearer-token-here' \
    --header 'Content-Type: application/json' \
    --header 'Accept: application/json'
    ```

    A `200` response with your profile data confirms that authentication is working correctly.
  </Step>

  <Step title="Add your first client">
    With authentication verified, create your first client record by posting to `/client/add`.

    ```bash
    curl --location 'https://fssportal.com/api/v1/client/add' \
    --header 'platform: WEB' \
    --header 'api-key: FSS2023' \
    --header 'Authorization: Bearer your-bearer-token-here' \
    --header 'Content-Type: application/json' \
    --header 'Accept: application/json' \
    --data-raw '{
        "name": "Acme Corp",
        "email": "contact@acme.com",
        "phone": "555-0100"
    }'
    ```

    The response returns the newly created client object, including its `id`. Use this `id` when creating rooms and measurements for the client.
  </Step>
</Steps>
