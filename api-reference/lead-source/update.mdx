---
title: "POST /lead-source/update — Update a Lead Source"
sidebarTitle: "Update Lead Source"
description: "POST /lead-source/update — Update an existing lead source record by ID. Accepts name, contact details, and address fields. Returns the updated record."
---

Use this endpoint to modify an existing lead source record. You must provide the `lead_source_id` to identify which record to update, along with the fields you want to change. The billing address fields are automatically kept in sync with the primary address fields on update. On success, the API returns the full updated record.

## Endpoint

```
POST https://fssportal.com/api/v1/lead-source/update
```

<Note>This endpoint requires authentication. Include your Bearer token in the `Authorization` header.</Note>

## Request headers

<ParamField header="platform" type="string" required>
  Must be `WEB`.
</ParamField>

<ParamField header="api-key" type="string" required>
  Your FSS API key. Use `FSS2023`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token from your login response. Format: `Bearer {your_token}`.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json`.
</ParamField>

## Request body

<ParamField body="lead_source_id" type="integer" required>
  The unique identifier of the lead source record to update. Obtain this from the `id` field in the list or add responses.
</ParamField>

<ParamField body="name" type="string" required>
  Updated first name of the lead source contact.
</ParamField>

<ParamField body="surname" type="string" required>
  Updated last name of the lead source contact.
</ParamField>

<ParamField body="email" type="string" required>
  Updated email address. Must be unique within your account.
</ParamField>

<ParamField body="company_name" type="string">
  Updated company or organization name. Optional.
</ParamField>

<ParamField body="phone_no" type="string">
  Updated phone number. Optional.
</ParamField>

<ParamField body="address" type="string">
  Updated street address. Optional.
</ParamField>

<ParamField body="city" type="string">
  Updated city. Optional.
</ParamField>

<ParamField body="state" type="string">
  Updated state or region. Optional.
</ParamField>

<ParamField body="zip_code" type="string">
  Updated postal or ZIP code. Optional.
</ParamField>

## Response fields

<ResponseField name="message" type="string">
  A human-readable status message, e.g. `"Lead Source updated successfully."`.
</ResponseField>

<ResponseField name="data" type="object">
  The full updated lead source record.
  <Expandable title="Lead source object">
    <ResponseField name="id" type="integer">
      Unique identifier of the lead source record.
    </ResponseField>
    <ResponseField name="user_id" type="integer">
      ID of the user account that owns this record.
    </ResponseField>
    <ResponseField name="company_name" type="string">
      Updated company name.
    </ResponseField>
    <ResponseField name="name" type="string">
      Updated first name.
    </ResponseField>
    <ResponseField name="surname" type="string">
      Updated last name.
    </ResponseField>
    <ResponseField name="email" type="string">
      Updated email address.
    </ResponseField>
    <ResponseField name="phone_no" type="string">
      Updated phone number.
    </ResponseField>
    <ResponseField name="address" type="string">
      Updated street address.
    </ResponseField>
    <ResponseField name="city" type="string">
      Updated city.
    </ResponseField>
    <ResponseField name="state" type="string">
      Updated state or region.
    </ResponseField>
    <ResponseField name="zip_code" type="string">
      Updated ZIP code.
    </ResponseField>
    <ResponseField name="billing_address" type="string">
      Billing street address, synced from `address`.
    </ResponseField>
    <ResponseField name="billing_city" type="string">
      Billing city, synced from `city`.
    </ResponseField>
    <ResponseField name="billing_state" type="string">

      Billing ZIP code, synced from `zip_code`.

    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of this update.
    </ResponseField>
  </Expandable>
</ResponseField>
