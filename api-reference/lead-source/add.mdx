title: "POST /lead-source/add — Create a Lead Source"

description: "POST /lead-source/add — Create a new lead source label to categorize where your clients come from, such as referral or social media."
---

Use this endpoint to create a new lead source record in your account. A lead source represents a contact or organization that refers clients to you — for example, a realtor, a social media channel, or a direct referral. The `email` field must be unique. On success, the API returns the newly created record, including the auto-assigned `id` and timestamps.

## Endpoint

```
POST https://fssportal.com/api/v1/lead-source/add
```

<Note>This endpoint requires authentication. Include your Bearer token in the `Authorization` header.</Note>

## Request headers

<ParamField header="platform" type="string" required>
  Must be `WEB`.
</ParamField>

<ParamField header="api-key" type="string" required>
  Your FSS API key. Use `FSS2023`.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer token from your login response. Format: `Bearer {your_token}`.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json`.
</ParamField>

## Request body

<ParamField body="name" type="string" required>
  First name of the lead source contact.
</ParamField>

<ParamField body="surname" type="string" required>
  Last name of the lead source contact.
</ParamField>

<ParamField body="email" type="string" required>
  Email address of the lead source contact. Must be unique within your account.
</ParamField>

<ParamField body="company_name" type="string">
  Company or organization name. Optional.
</ParamField>

<ParamField body="phone_no" type="string">
  Phone number for the lead source contact. Optional.
</ParamField>

<ParamField body="address" type="string">
  Street address. Optional. Also used as the billing address if no separate billing address is provided.
</ParamField>

<ParamField body="city" type="string">
  City. Optional.
</ParamField>

<ParamField body="state" type="string">
  State or region. Optional.
</ParamField>

<ParamField body="zip_code" type="string">
  Postal or ZIP code. Optional.
</ParamField>
