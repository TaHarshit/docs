title: "POST /user/delete_account — Delete Your Account"
sidebarTitle: "Delete Account"

---

Use this endpoint to permanently delete your FSS Measurement account. Once submitted, your account, all associated measurements, projects, and company data are removed and cannot be recovered.

<Warning>
  This action is irreversible. All data linked to your account — including measurements, projects, and company associations — will be permanently deleted. There is no way to undo this operation.
</Warning>

## Endpoint

```
POST https://fssportal.com/api/v1/user/delete_account
```

## Required headers

| Header          | Value                 |
| --------------- | --------------------- |
| `platform`      | `WEB`                 |
| `api-key`       | `FSS2023`             |
| `Authorization` | `Bearer {your_token}` |
| `Content-Type`  | `application/json`    |

## Request body

No request body parameters are required. Send an empty JSON object.

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the account has been deleted.
</ResponseField>

<ResponseField name="data" type="object">
  The result of the deletion.

  <Expandable title="data properties">
    <ResponseField name="message" type="string">
      A human-readable confirmation, e.g. `"Account deleted successfully"`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<RequestExample>

```bash cURL
curl --request POST \
  --url https://fssportal.com/api/v1/user/delete_account \
  --header 'platform: WEB' \
  --header 'api-key: FSS2023' \
  --header 'Authorization: Bearer {your_token}' \
  --header 'Content-Type: application/json' \
  --data '{}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": "success",
  "data": {
    "message": "Account deleted successfully"
  }
}
```

```json 401
{
  "status": "error",
  "message": "Unauthorized"
}
```

</ResponseExample>
