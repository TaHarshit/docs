---

Use this endpoint to trigger a password reset email for a registered user. The API sends a time-limited reset link to the provided address. You do not need to be authenticated to call this endpoint.

## Endpoint

```
POST https://fssportal.com/api/v1/user/forgot_password
```

## Request headers

| Header | Value | Required |
|---|---|---|
| `api-key` | `FSS2023` | Yes |
| `platform` | `WEB`, `IOS`, or `ANDROID` | Yes |
| `Content-Type` | `application/json` | Yes |

## Request body

<ParamField body="email" type="string" required>
  The email address associated with the account. The API sends the reset link to this address.
</ParamField>

## Example request

```bash
curl --location 'https://fssportal.com/api/v1/user/forgot_password' \
  --header 'api-key: FSS2023' \
  --header 'platform: WEB' \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "email": "john.doe@example.com"
  }'
```

## Success response — 200 OK

```json
{
  "message": "Password reset link has been sent to your email address."
}
```

<Note>
  If the reset email does not arrive within a few minutes, ask the user to check their spam or junk folder. The reset link is valid for 60 minutes and can only be used once.
</Note>

## Password reset flow

<Steps>
  <Step title="Request reset">
    Submit the user's email address to this endpoint.
  </Step>
  <Step title="Receive email">
    The user receives an email containing a password reset link with an embedded token.
  </Step>
  <Step title="Follow the link">
    The user clicks the link, which directs them to the reset form with the token pre-populated.
  </Step>
  <Step title="Set new password">
    Submit the token and new password to `POST /user/reset_password/{token}` to complete the reset.
  </Step>
</Steps>
