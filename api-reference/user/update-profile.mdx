Use this endpoint to update the profile information of the currently authenticated user. You can update one or more fields in a single request. When uploading a `profile_image`, send the request as `multipart/form-data` instead of JSON.

## Endpoint

```
POST https://fssportal.com/api/v1/user/update_profile
```

## Required headers

| Header          | Value                                              |
| --------------- | -------------------------------------------------- |
| `platform`      | `WEB`                                              |
| `api-key`       | `FSS2023`                                          |
| `Authorization` | `Bearer {your_token}`                              |
| `Content-Type`  | `application/json` or `multipart/form-data` for image uploads |

<Note>
  When including a `profile_image` file, set `Content-Type` to `multipart/form-data`. For text-only updates, use `application/json`.
</Note>

## Request body parameters

All parameters are optional. Include only the fields you want to update.

<ParamField body="name" type="string">
  The user's full name.
</ParamField>

<ParamField body="first_name" type="string">
  The user's first name.
</ParamField>

<ParamField body="last_name" type="string">
  The user's last name.
</ParamField>

<ParamField body="phone" type="string">
  The user's phone number.
</ParamField>

<ParamField body="country_code" type="string">
  International dialing code, e.g. `"+1"`.
</ParamField>

<ParamField body="own_company_name" type="string">
  Display name for the user's company.
</ParamField>

<ParamField body="email" type="string">
  The user's email address.
</ParamField>

<ParamField body="profile_image" type="file">
  A profile photo to upload. Send as `multipart/form-data`. Accepted formats: JPEG, PNG.
</ParamField>

<ParamField body="measurement_unit" type="string">
  Preferred unit system. Accepted values: `"Imperial"`, `"Metric"`.
</ParamField>

## Response fields

<ResponseField name="status" type="string">
  `"success"` on a successful update.
</ResponseField>

<ResponseField name="data" type="object">
  The update result.

  <Expandable title="data properties">
    <ResponseField name="message" type="string">
      A human-readable confirmation, e.g. `"Profile updated successfully"`.
    </ResponseField>
    <ResponseField name="user" type="object">
      The updated user object.

      <Expandable title="user properties">
        <ResponseField name="id" type="integer">
          Unique numeric identifier for the user.
        </ResponseField>
        <ResponseField name="first_name" type="string">
          Updated first name.
        </ResponseField>
        <ResponseField name="last_name" type="string">
          Updated last name.
        </ResponseField>
        <ResponseField name="email" type="string">
          The user's email address.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<RequestExample>

```bash cURL
curl --request POST \
  --url https://fssportal.com/api/v1/user/update_profile \
  --header 'platform: WEB' \
  --header 'api-key: FSS2023' \
  --header 'Authorization: Bearer {your_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "first_name": "Jane",
    "last_name": "Doe",
    "phone": "5550001234",
    "own_company_name": "Acme Blinds Co."
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": "success",
  "data": {
    "message": "Profile updated successfully",
    "user": {
      "id": 68,
      "first_name": "Jane",
      "last_name": "Doe",
      "email": "user@example.com"
    }
  }
}
```

```json 422
{
  "status": "error",
  "message": "Validation failed"
}
```

</ResponseExample>
