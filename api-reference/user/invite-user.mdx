Use this endpoint to invite a new user to join your FSS Measurement company account. The API sends an invitation email to the specified address. Once accepted, the invitee is added to your company and can collaborate on measurements and projects.

## Endpoint

```
POST https://fssportal.com/api/v1/user/invite_user
```

## Required headers

| Header          | Value                 |
| --------------- | --------------------- |
| `platform`      | `WEB`                 |
| `api-key`       | `FSS2023`             |
| `Authorization` | `Bearer {your_token}` |
| `Content-Type`  | `application/json`    |

## Request body parameters

<ParamField body="email" type="string" required>
  The email address of the person you want to invite. An invitation email is sent to this address.
</ParamField>

<ParamField body="role" type="string">
  The role to assign to the invitee. Accepted values: `"admin"`, `"member"`. Defaults to `"member"` if not provided.
</ParamField>

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the invitation is sent successfully.
</ResponseField>

<ResponseField name="data" type="object">
  Details of the sent invitation.

  <Expandable title="data properties">
    <ResponseField name="message" type="string">
      A human-readable confirmation, e.g. `"User invited successfully"`.
    </ResponseField>
    <ResponseField name="invite_link" type="string">
      The unique invitation URL sent to the invitee.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<RequestExample>

```bash cURL
curl --request POST \
  --url https://fssportal.com/api/v1/user/invite_user \
  --header 'platform: WEB' \
  --header 'api-key: FSS2023' \
  --header 'Authorization: Bearer {your_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "newmember@example.com",
    "role": "member"
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": "success",
  "data": {
    "message": "User invited successfully",
    "invite_link": "https://fssportal.com/api/v1/invite/token123"
  }
}
```

```json 422
{
  "status": "error",
  "message": "User already exists"
}
```

</ResponseExample>
