---
title: "POST /user/reset_password — Set a New Password"
sidebarTitle: "Reset Password"
description: "POST /user/reset_password/{token} — Reset a user's password using a valid reset token. Accepts the token, new password, and confirmation."
---

Use this endpoint to set a new password after a user has received a reset link via email. You must supply the token from the reset link along with the desired new password and its confirmation. The token is single-use and expires after 60 minutes.

## Endpoint

```
POST https://fssportal.com/api/v1/user/reset_password/{token}
```

## Request headers

| Header | Value | Required |
|---|---|---|
| `api-key` | `FSS2023` | Yes |
| `platform` | `WEB`, `IOS`, or `ANDROID` | Yes |
| `Content-Type` | `application/json` | Yes |

## Path parameters

<ParamField path="token" type="string" required>
  The password reset token extracted from the link in the reset email. Tokens are valid for 60 minutes and can only be used once.
</ParamField>

## Request body

<ParamField body="password" type="string" required>
  The new password for the account. Must be at least 8 characters.
</ParamField>

<ParamField body="password_confirmation" type="string" required>
  Must exactly match the value of `password`.
</ParamField>

## Example request

```bash
curl --location 'https://fssportal.com/api/v1/user/reset_password/abc123token456' \
  --header 'api-key: FSS2023' \
  --header 'platform: WEB' \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "password": "NewSecurePass456",
    "password_confirmation": "NewSecurePass456"
  }'
```

## Success response — 200 OK

```json
{
  "message": "Your password has been reset successfully. Please sign in with your new password."
}
```

After a successful reset, direct the user to the sign-in flow. All previously issued `api_token` values for the account are invalidated.

## Error responses

**Invalid or expired token — 400 Bad Request:**

```json
{
  "message": "Invalid or expired reset token.",
  "status": 400
}
```

**Validation failure — 422 Unprocessable Entity:**

```json
{
  "message": "The given data was invalid.",
  "errors": {
    "password": [
      "The password confirmation does not match."
    ]
  },
  "status": 422
}
```

<Warning>
  If a user's token has expired, they must restart the process by calling `POST /user/forgot_password` again to receive a new reset link.
</Warning>
