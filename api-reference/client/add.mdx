---
title: "POST /client/add — Create a New Client"
sidebarTitle: "Add Client"
description: "POST /client/add — Create a new client record with contact details, address, and optional lead source. Returns the created client object."
---

Use this endpoint to create a new client record in your FSS account. You provide the client's contact information, service address, billing address, and an optional lead source reference. The API returns a confirmation message once the record is saved. Use this when onboarding a new client before creating quotes or measurement orders.

## Endpoint

```
POST https://fssportal.com/api/v1/client/add
```

## Required headers

| Header | Value |
|---|---|
| `platform` | `WEB` |
| `api-key` | `FSS2023` |
| `Authorization` | `Bearer {your_token}` |
| `Content-Type` | `application/json` |

## Request body

<ParamField body="name" type="string" required>
  The client's first name.
</ParamField>

<ParamField body="surname" type="string" required>
  The client's last name.
</ParamField>

<ParamField body="email" type="string" required>
  The client's email address. Must be unique within your account unless a `location` value is also provided.
</ParamField>

<ParamField body="location" type="string">
  The project site or location identifier for this client. Required when reusing an email address across multiple client records.
</ParamField>

<ParamField body="phone" type="string">
  The client's primary phone number.
</ParamField>

<ParamField body="phone_no" type="string">
  An additional phone number for the client.
</ParamField>

<ParamField body="address" type="string">
  The client's service street address.
</ParamField>

<ParamField body="city" type="string">
  The city for the service address.
</ParamField>

<ParamField body="state" type="string">
  The state for the service address.
</ParamField>

<ParamField body="zip_code" type="string">
  The ZIP code for the service address.
</ParamField>

<ParamField body="billing_address" type="string">
  The client's billing street address. Defaults to the service address if omitted.
</ParamField>

<ParamField body="billing_city" type="string">
  The city for the billing address.
</ParamField>

<ParamField body="billing_state" type="string">
  The state for the billing address.
</ParamField>

<ParamField body="billing_zip_code" type="string">
  The ZIP code for the billing address.
</ParamField>

<ParamField body="lead_source_id" type="integer">
  The ID of the lead source to associate with this client. Retrieve available IDs from `GET /lead_source/get`.
</ParamField>

<ParamField body="lead_source_name" type="string">
  The name of the lead source. Used for display purposes alongside `lead_source_id`.
</ParamField>

<ParamField body="quote_no" type="string">
  A quote number to associate with this client record. Should be unique for tracking purposes.
</ParamField>

<ParamField body="project_name" type="string">
  The name of the project associated with this client.
</ParamField>

<ParamField body="end_client_known" type="boolean">
  Set to `true` if the end client's identity is known at the time of record creation.
</ParamField>

## Response fields

<ResponseField name="message" type="string">
  A confirmation message indicating the result of the operation.
</ResponseField>

<ResponseField name="data" type="array">
  An empty array returned on successful creation. Retrieve the created record using `GET /client/list`.
</ResponseField>

## Example request

```bash
curl --request POST \
  --url https://fssportal.com/api/v1/client/add \
  --header 'platform: WEB' \
  --header 'api-key: FSS2023' \
  --header 'Authorization: Bearer {your_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "John",
    "surname": "Doe",
    "email": "john.doe@example.com",
    "location": "Rajkot",
    "phone": "1234567890",
    "address": "123 Main St",
    "city": "Rajkot",
    "state": "Gujarat",
    "zip_code": "360006",
    "billing_address": "123 Main St",
    "billing_city": "Rajkot",
    "billing_state": "Gujarat",
    "billing_zip_code": "360006",
    "phone_no": "7023927561",
    "lead_source_name": "",
    "quote_no": "QT-2024-001",
    "lead_source_id": 17,
    "project_name": "Rajkot Residential",
    "end_client_known": true
  }'
```

## Success response

```json
{
  "message": "Client added successfully.",
  "data": []
}
```

## Error responses

```json 422 Validation error
{
  "message": "The given data was invalid.",
  "errors": {
    "email": ["The email field is required."],
    "name": ["The name field is required."]
  }
}
```

```json 401 Unauthorized
{
  "message": "Unauthenticated."
}
```
