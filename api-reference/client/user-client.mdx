---
title: "POST /client/user-client — Get Clients by User"
sidebarTitle: "User Clients"
description: "POST /client/user-client — Returns all client records owned by a specific team member in your company account. Useful for multi-user workflows and reporting."
---

Use this endpoint to retrieve all client records belonging to a specific user within your company account. You identify the user by their company identifier, and the API returns the full list of clients they own. This is useful in multi-user company accounts where you need to view or manage clients across team members.

## Endpoint

```
POST https://fssportal.com/api/v1/client/user-client
```

## Required headers

| Header | Value |
|---|---|
| `platform` | `WEB` |
| `api-key` | `FSS2023` |
| `Authorization` | `Bearer {your_token}` |
| `Content-Type` | `application/json` |

## Request body

<ParamField body="company_name" type="string" required>
  The company identifier used to look up the user whose clients you want to retrieve. This is typically the company's unique ID or registration number.
</ParamField>

## Response fields

<ResponseField name="message" type="string">
  A status message for the request.
</ResponseField>

        </ResponseField>

        </ResponseField>
        <ResponseField name="billing_address" type="string">
          The billing street address.

        <ResponseField name="billing_city" type="string">
          The city for the billing address.
        </ResponseField>
        <ResponseField name="billing_state" type="string">
          The state for the billing address.

        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Example request

```bash
curl --request POST \
  --url https://fssportal.com/api/v1/client/user-client \
  --header 'platform: WEB' \
  --header 'api-key: FSS2023' \
  --header 'Authorization: Bearer {your_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "company_name": "630311275"
  }'
```
