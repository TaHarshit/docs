---
title: "GET /client/list — List All Clients"
sidebarTitle: "List Clients"
description: "GET /client/list — Returns a paginated list of all client records for the authenticated user. Supports keyword filtering and page-based navigation."
---

Use this endpoint to retrieve a paginated list of all client records associated with your account. You can optionally pass a keyword to filter results and control the page number and page size. The response includes full client details for each record along with pagination metadata so you can iterate through large result sets.

## Endpoint

```
GET https://fssportal.com/api/v1/client/list
```

## Required headers

| Header | Value |
|---|---|
| `platform` | `WEB` |
| `api-key` | `FSS2023` |
| `Authorization` | `Bearer {your_token}` |
| `Content-Type` | `application/json` |

## Request body

<ParamField body="keyword" type="string">
  Filter results to clients whose name, email, or other fields contain this string. Omit to return all clients.
</ParamField>

<ParamField body="page" type="integer" default="1">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField body="limit" type="integer" default="20">
  The number of records to return per page. Defaults to `20`.
</ParamField>

## Example request

```bash
curl --request GET \
  --url https://fssportal.com/api/v1/client/list \
  --header 'platform: WEB' \
  --header 'api-key: FSS2023' \
  --header 'Authorization: Bearer {your_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "keyword": "john",
    "page": 1,
    "limit": 10
  }'
```
