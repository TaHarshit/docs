---
title: "POST /measurements/series_window — Series with Draperies"
sidebarTitle: "Series & Draperies"
description: "POST /measurements/series_window — Record a window series measurement with drapery details including rod type, fullness, and fabric."
---

Use this endpoint to record measurements for a series of windows treated as a single drapery installation — for example, two or three windows sharing a continuous curtain rod. You supply per-window dimensions for each window in the series (labeled A through E) together with the room-level measurements needed to size the drapery, including wall-to-wall width, floor-to-ceiling height, curtain rod length, rod-to-floor drop, and trim details. Pass `0` for `id` to create a new record, or supply an existing ID to update it.

## Endpoint

```
POST https://fssportal.com/api/v1/measurements/series_window_with_draperies_add_edit
```

## Required Headers

| Header          | Value                  |
| --------------- | ---------------------- |
| `platform`      | `WEB`                  |
| `api-key`       | `FSS2023`              |
| `Authorization` | `Bearer {your_token}`  |
| `Content-Type`  | `application/json`     |

## Request Body

### Core fields

<ParamField body="id" type="integer">
  The ID of an existing measurement to update. Pass `0` to create a new record.
</ParamField>

<ParamField body="user_id" type="integer" required>
  The ID of the user recording the measurement.
</ParamField>

<ParamField body="client_id" type="integer" required>
  The ID of the client this measurement belongs to.
</ParamField>

<ParamField body="room_id" type="integer" required>
  The ID of the room where the window series is located.
</ParamField>

<ParamField body="measurement_type_id" type="integer" required>
  The measurement type identifier. Pass `1` for a standard series with draperies measurement.
</ParamField>

<ParamField body="window_name" type="string" required>
  A descriptive label for the series, e.g. `"Living Room Bay Series"`.

<ParamField body="unit_type" type="string" required>

</ParamField>

</ParamField>

<ParamField body="number_in_series" type="string">
