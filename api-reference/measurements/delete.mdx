Use this endpoint to permanently delete a measurement record by its ID. This applies to all measurement types — single window, single window photo, multiple window, specialty window, series with draperies, and awning. Once deleted the record cannot be recovered, so confirm the correct `measurement_id` before calling this endpoint.

<Warning>
  **This action is permanent and cannot be undone.** Deleting a measurement removes all associated dimension data, notes, and attached images from the FSS system. There is no soft-delete or recycle bin. Verify the `measurement_id` before making this request.
</Warning>

## Endpoint

```
POST https://fssportal.com/api/v1/measurements/delete
```

## Required Headers

| Header          | Value                  |
| --------------- | ---------------------- |
| `platform`      | `WEB`                  |
| `api-key`       | `FSS2023`              |
| `Authorization` | `Bearer {your_token}`  |
| `Content-Type`  | `application/json`     |

## Request Body

<ParamField body="measurement_id" type="integer" required>
  The unique ID of the measurement record to delete. You can retrieve this value from the `id` field returned by the [Get Measurements](/api-reference/measurements/get) endpoint.
</ParamField>

## Response

A successful deletion returns HTTP `200` with a `null` body. No confirmation object is returned.

<ResponseField name="(empty)" type="null">
  The response body is `null` on success.
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://fssportal.com/api/v1/measurements/delete \
  --header "platform: WEB" \
  --header "api-key: FSS2023" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  --header "Content-Type: application/json" \
  --data '{
    "measurement_id": 12170
  }'
```

</RequestExample>

<ResponseExample>

null

```json 422 Validation Error

```

</ResponseExample>
