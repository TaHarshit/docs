---
title: "POST /measurements/specialty_window — Specialty Window"
sidebarTitle: "Specialty Window"
description: "POST /measurements/specialty_window — Record a specialty or non-standard window measurement with shape type and custom dimensions."
---

Use this endpoint to record measurements for non-rectangular or specialty windows such as arches, trapezoids, triangles, or other custom shapes. Because specialty windows vary by geometry, the dimension fields (`a` through `l`, `w`, `r`, `w1`–`w2`, `h1`–`h2`, etc.) map to shape-specific points defined by the `window_type`. Omit or leave empty any fields that are not applicable to the selected shape. Pass `0` for `id` to create a new record, or supply an existing ID to update it.

## Endpoint

```
POST https://fssportal.com/api/v1/measurements/specialty_window_add_edit
```

## Required Headers

| Header          | Value                  |
| --------------- | ---------------------- |
| `platform`      | `WEB`                  |
| `api-key`       | `FSS2023`              |
| `Authorization` | `Bearer {your_token}`  |
| `Content-Type`  | `application/json`     |

## Request Body

<ParamField body="id" type="integer">
  The ID of an existing measurement to update. Pass `0` to create a new record.
</ParamField>

<ParamField body="user_id" type="integer" required>
  The ID of the user recording the measurement.
</ParamField>

<ParamField body="client_id" type="integer" required>
  The ID of the client this measurement belongs to.
</ParamField>

<ParamField body="room_id" type="integer" required>
  The ID of the room where the window is located.
</ParamField>

<ParamField body="measurement_type_id" type="integer" required>
  The measurement type identifier. Pass `1` for standard specialty window measurements.
</ParamField>

<ParamField body="window_name" type="string" required>
  A descriptive label for the window, e.g. `"Entry Arch"`.
</ParamField>

<ParamField body="window_type" type="integer" required>
  Numeric code identifying the shape of the specialty window (e.g. `1` = Arch, `2` = Quarter Circle, `3` = Trapezoid). Refer to your FSS account's shape reference for the full list.
</ParamField>

<ParamField body="unit_type" type="string" required>
  The unit system for all dimension values. Accepted values: `"Imperial"`, `"Metrix"`.
</ParamField>

<ParamField body="mount_type" type="string">
  How the covering is mounted: `"Inside"` or `"Outside"`.
</ParamField>

<ParamField body="a" type="string">
  Shape dimension A. Meaning depends on `window_type` (e.g. base width for a trapezoid).
</ParamField>

<ParamField body="b" type="string">
  Shape dimension B.
</ParamField>

<ParamField body="c" type="string">
  Shape dimension C.
</ParamField>

<ParamField body="d" type="string">
  Shape dimension D.
</ParamField>

<ParamField body="e" type="string">
  Shape dimension E.
</ParamField>

<ParamField body="f" type="string">
  Shape dimension F.
</ParamField>

<ParamField body="g" type="string">
  Shape dimension G.
</ParamField>

<ParamField body="h" type="string">
  Shape dimension H.
</ParamField>

<ParamField body="i" type="string">
  Shape dimension I.
</ParamField>

<ParamField body="j" type="string">
  Shape dimension J.
</ParamField>

<ParamField body="k" type="string">
  Shape dimension K.
</ParamField>

<ParamField body="l" type="string">
  Shape dimension L.
</ParamField>

<ParamField body="w" type="string">
  Overall width of the specialty window opening.
</ParamField>

<ParamField body="r" type="string">
  Radius measurement, used for arched or circular window shapes.
</ParamField>

<ParamField body="w1" type="string">
  Secondary width measurement for compound shapes.
</ParamField>

<ParamField body="h1" type="string">
  Primary height measurement for the shape.
</ParamField>

<ParamField body="d1" type="string">
  Primary depth measurement for the shape.
</ParamField>

<ParamField body="x1" type="string">
  Horizontal offset or inset measurement, point 1.
</ParamField>

<ParamField body="b1" type="string">
  Secondary base measurement, point 1.
</ParamField>

<ParamField body="w2" type="string">
  Tertiary width measurement for compound shapes.
</ParamField>

<ParamField body="h2" type="string">
  Secondary height measurement for the shape.
</ParamField>

<ParamField body="d2" type="string">
  Secondary depth measurement for the shape.
</ParamField>

<ParamField body="x2" type="string">
  Horizontal offset or inset measurement, point 2.
</ParamField>

<ParamField body="b2" type="string">
  Secondary base measurement, point 2.
</ParamField>

<ParamField body="for_shutter" type="string">
  Indicates whether this measurement is for a shutter product.
</ParamField>

<ParamField body="square_feet" type="string">
  Calculated or estimated square footage of the window area.
</ParamField>

<ParamField body="focus_width" type="string">
  Solatech Focus integration width value.
</ParamField>

<ParamField body="focus_width_key" type="string">
  Key identifier for the Solatech Focus width field.
</ParamField>

<ParamField body="focus_height" type="string">
  Solatech Focus integration height value.
</ParamField>

<ParamField body="focus_height_key" type="string">
  Key identifier for the Solatech Focus height field.
</ParamField>

<ParamField body="offset_value" type="string">
  Offset adjustment value applied to the measurement.
</ParamField>

<ParamField body="offset_value_keys" type="string">
  Keys identifying which fields the offset applies to.
</ParamField>

<ParamField body="min_value_fields" type="string">
  Minimum value constraints for specific dimension fields.
</ParamField>

<ParamField body="note" type="string">
  Free-text notes about this measurement or installation context.
</ParamField>

<ParamField body="installation_instructions" type="string">
  Specific installation instructions for this window.
</ParamField>

<ParamField body="total_custom_fields" type="integer">
  The count of custom fields included in `custom_field`.
</ParamField>

<ParamField body="custom_field" type="object">
  A key-value map of custom measurement fields defined for your account. Pass an empty array `[]` when unused.
</ParamField>

## Response

<ResponseField name="message" type="string">
  A human-readable confirmation, e.g. `"Measurement added successfully!"`.
</ResponseField>

<ResponseField name="data" type="array">
  An empty array on success. Populated with error detail when validation fails.
</ResponseField>
