---
title: "POST /measurements/awning — Record an Awning Measurement"
sidebarTitle: "Awning"
description: "POST /measurements/awning — Record an awning measurement for a room. Accepts width, projection depth, height, clearances, bracket data, and room context."
---

Use this endpoint to record an awning measurement for a client's property. You supply the physical dimensions of the awning opening — including width, projection depth, height, clearances, and bracket data — along with the client and room context. Pass `0` for `id` to create a new record, or provide an existing ID to update it.

## Endpoint

```
POST https://fssportal.com/api/v1/measurements/awning_measurement_add_edit
```

## Required Headers

| Header          | Value                  |
| --------------- | ---------------------- |
| `platform`      | `WEB`                  |
| `api-key`       | `FSS2023`              |
| `Authorization` | `Bearer {your_token}`  |
| `Content-Type`  | `application/json`     |

## Request Body

<ParamField body="id" type="integer">
  The ID of an existing awning measurement to update. Pass `0` to create a new record.
</ParamField>

<ParamField body="user_id" type="integer" required>
  The ID of the user recording the measurement.
</ParamField>

<ParamField body="client_id" type="integer" required>
  The ID of the client this measurement belongs to.
</ParamField>

<ParamField body="room_id" type="integer" required>
  The ID of the room or exterior area where the awning is located.
</ParamField>

<ParamField body="measurement_type_id" type="integer" required>
  The measurement type identifier. Pass `1` for a standard awning measurement.
</ParamField>

<ParamField body="window_name" type="string" required>
  A descriptive label for the awning location, e.g. `"Rear Patio Awning"`.
</ParamField>

<ParamField body="unit_type" type="string" required>
  The unit system for all dimension values. Accepted values: `"Imperial"`, `"Metrix"`.
</ParamField>

<ParamField body="mount_type" type="string">
  How the awning is mounted, e.g. `"Wall"`, `"Soffit"`, `"Roof"`.
</ParamField>

<ParamField body="awning_config" type="string">
  Awning configuration or style, e.g. `"retractable"`, `"fixed"`, `"lateral-arm"`.
</ParamField>

<ParamField body="width" type="string">
  Overall width of the awning opening.
</ParamField>

<ParamField body="height" type="string">
  Height of the awning mounting area from grade or floor level.
</ParamField>

<ParamField body="projection_lenth" type="string">
  Projection depth — how far the awning extends from the wall when fully open.
</ParamField>

<ParamField body="coverage_depth" type="string">
  Effective coverage depth provided by the awning when deployed.
</ParamField>

<ParamField body="valance_height" type="string">
  Height of the front valance drop.
</ParamField>

<ParamField body="headroom" type="string">
  Clearance between the mounting point and any overhead obstruction.
</ParamField>

<ParamField body="opening_clearance" type="string">
  Clearance required for the awning mechanism to open without obstruction.
</ParamField>

<ParamField body="width_cassette" type="string">
  Width of the cassette housing (for cassette-style retractable awnings).
</ParamField>

<ParamField body="left_clearance" type="string">
  Clearance available to the left of the awning installation zone.
</ParamField>

<ParamField body="right_clearance" type="string">
  Clearance available to the right of the awning installation zone.
</ParamField>

<ParamField body="angle" type="string">
  Pitch angle of the awning in degrees.
</ParamField>

<ParamField body="standoff_bracket" type="string">
  Standoff bracket depth or type required for the installation.
</ParamField>

<ParamField body="bracket_data" type="string">
  Additional bracket specification data, e.g. bracket model or anchor type.
</ParamField>

<ParamField body="square_feet" type="string">
  Calculated or estimated square footage of the awning coverage area.
</ParamField>

<ParamField body="for_shutter" type="string">
  Indicates whether this measurement record is also used for a shutter product.
</ParamField>

<ParamField body="focus_width" type="string">
  Solatech Focus integration width value.
</ParamField>

<ParamField body="focus_width_key" type="string">
  Key identifier for the Solatech Focus width field.
</ParamField>

<ParamField body="focus_height" type="string">
  Solatech Focus integration height value.
</ParamField>

<ParamField body="focus_height_key" type="string">
  Key identifier for the Solatech Focus height field.
</ParamField>

<ParamField body="offset_value" type="string">
  Offset adjustment value applied to the measurement.
</ParamField>

<ParamField body="offset_value_keys" type="string">
  Keys identifying which fields the offset applies to.
</ParamField>

<ParamField body="measurement_unique_id" type="string">
  Optional unique identifier used for Solatech Focus integration.
</ParamField>

<ParamField body="min_value_fields" type="string">
  Minimum value constraints for specific dimension fields.
</ParamField>

<ParamField body="note" type="string">
  Free-text notes about this measurement or installation context.
</ParamField>

<ParamField body="installation_instructions" type="string">
  Specific installation instructions for this awning.
</ParamField>

<ParamField body="total_custom_fields" type="integer">
  The count of custom fields included in `custom_field`.
</ParamField>

<ParamField body="custom_field" type="object">
  A key-value map of custom measurement fields defined for your account. Pass an empty array `[]` when unused.
</ParamField>

## Response

<ResponseField name="message" type="string">
  A human-readable confirmation, e.g. `"Measurement added successfully!"`.
</ResponseField>

<ResponseField name="data" type="array">
  An empty array on success. Populated with error detail when validation fails.
</ResponseField>
