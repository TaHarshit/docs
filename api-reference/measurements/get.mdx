---
title: "GET /measurements/get — Retrieve Measurements"
sidebarTitle: "Get Measurements"
description: "GET /measurements/get — Retrieve window measurements filtered by room or client ID. Returns an array of measurement objects with details."
---

Use this endpoint to retrieve existing measurements for a client. You can filter results by room, group, and measurement type. The response includes a `measurements` array where each object contains the full set of dimension fields recorded for that window — spanning standard, specialty, series, and awning types — with `null` returned for fields that are not applicable to a given record.

<Note>
  Although this endpoint is labelled `GET` in the API reference title, it accepts its filter parameters as a JSON body and must be called with the `POST` HTTP method.
</Note>

## Endpoint

```
POST https://fssportal.com/api/v1/measurements/get
```

## Required Headers

| Header          | Value                  |
| --------------- | ---------------------- |
| `platform`      | `WEB`                  |
| `api-key`       | `FSS2023`              |
| `Authorization` | `Bearer {your_token}`  |
| `Content-Type`  | `application/json`     |

## Request Body

<ParamField body="client_id" type="integer" required>
  The ID of the client whose measurements you want to retrieve.
</ParamField>

<ParamField body="room_id" type="integer">
  Filter results to a specific room. Omit to return measurements across all rooms for the client.
</ParamField>

<ParamField body="group_id" type="integer" required>
  The ID of the measurement group. Required to scope results to the correct group.
</ParamField>

<ParamField body="measurement_type_id" type="integer" required>
  Filter by measurement type (e.g. `1` = single window photo, `2` = specialty, `3` = series with draperies, `4` = awning).
</ParamField>
