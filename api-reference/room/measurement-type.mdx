---
title: "GET /room/measurement_type — List Measurement Types"
sidebarTitle: "Measurement Types"
description: "GET /room/measurement_type — Returns all supported measurement types with IDs and names. Use the returned IDs when assigning a measurement type to a room."
---

Use this endpoint to retrieve the complete list of measurement types supported by the FSS Measurement API. Each measurement type defines the form and data structure used when capturing window measurements in a room. You reference the `id` from this response when setting the measurement type on a room or when submitting measurement data.

## Endpoint

```
GET https://fssportal.com/api/v1/room/measurement_type
```

## Headers

| Header          | Value                  | Required |
|-----------------|------------------------|----------|
| `platform`      | `WEB`                  | Yes      |
| `api-key`       | `FSS2023`              | Yes      |
| `Authorization` | `Bearer {your_token}`  | Yes      |
| `Content-Type`  | `application/json`     | Yes      |

## Request Body

This endpoint does not require a request body.

## Response

<ResponseField name="message" type="string">
  A human-readable status message, for example `"Measurement type get successfully."`.
</ResponseField>

<ResponseField name="data" type="array">
  An array of measurement type objects representing all available options.
  <Expandable title="data item">
    <ResponseField name="id" type="integer">
      The unique numeric ID of the measurement type. Use this value when assigning a measurement type to a room or submitting measurements.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the measurement type, for example `"Single Window"` or `"Multi Window"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --location 'https://fssportal.com/api/v1/room/measurement_type' \
--header 'platform: WEB' \
--header 'api-key: FSS2023' \
--header 'Authorization: Bearer {your_token}' \
--header 'Content-Type: application/json'
```

</RequestExample>
