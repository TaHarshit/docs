---
title: "POST /room/update — Update Room Details"
sidebarTitle: "Update Room"
description: "POST /room/update — Update an existing room by ID. Accepts name, measurement type, and other room attributes. Omitted fields are left unchanged."
---

Use this endpoint to modify the details of an existing room. You identify the room by its ID and supply the fields you want to change. Any field you omit remains unchanged. This is useful for correcting a room name or reassigning a room type after initial creation.

## Endpoint

```
POST https://fssportal.com/api/v1/room/update
```

## Headers

| Header          | Value                  | Required |
|-----------------|------------------------|----------|
| `platform`      | `WEB`                  | Yes      |
| `api-key`       | `FSS2023`              | Yes      |
| `Authorization` | `Bearer {your_token}`  | Yes      |
| `Content-Type`  | `application/json`     | Yes      |

## Request Body

<ParamField body="room_id" type="integer" required>
  The unique ID of the room you want to update. You receive this ID from the `POST /room/add` or `GET /room/get` endpoints.
</ParamField>

<ParamField body="name" type="string">
  The new display name for the room. Replaces the existing name when provided.
</ParamField>

## Response

<ResponseField name="message" type="string">
  A human-readable confirmation message, for example `"Room updated successfully."`.
</ResponseField>

<ResponseField name="data" type="array">
  An empty array returned on a successful update.
</ResponseField>

<RequestExample>

```bash cURL
curl --location 'https://fssportal.com/api/v1/room/update' \
--header 'platform: WEB' \
--header 'api-key: FSS2023' \
--header 'Authorization: Bearer {your_token}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "room_id": 4945,
  "name": "Master Bedroom"
}'
```

</RequestExample>

<ResponseExample>

```json 200 Success
{
  "message": "Room updated successfully.",
  "data": []
}
```

```json 401 Unauthorized
{
  "message": "Unauthenticated."
}
```

```json 422 Unprocessable Entity
{
  "message": "The room_id field is required.",
  "errors": {
    "room_id": ["The room_id field is required."]
  }
}
```

```json 404 Not Found
{
  "message": "Room not found."
}
```

</ResponseExample>
