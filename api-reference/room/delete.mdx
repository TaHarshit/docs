---
title: "POST /room/delete — Delete a Room"
sidebarTitle: "Delete Room"
description: "POST /room/delete — Permanently delete a room and all its measurements from a client project by room ID. This action cannot be undone."
---

Use this endpoint to permanently delete a room from a client project. You identify the room by its ID. The deletion cannot be undone through the API.

<Warning>
  Deleting a room permanently removes all measurements associated with that room. This action cannot be undone. Retrieve and back up any measurement data before calling this endpoint.
</Warning>

## Endpoint

```
POST https://fssportal.com/api/v1/room/delete
```

## Headers

| Header          | Value                  | Required |
|-----------------|------------------------|----------|
| `platform`      | `WEB`                  | Yes      |
| `api-key`       | `FSS2023`              | Yes      |
| `Authorization` | `Bearer {your_token}`  | Yes      |
| `Content-Type`  | `application/json`     | Yes      |

## Request Body

<ParamField body="room_id" type="integer" required>
  The unique ID of the room to delete. You can retrieve room IDs from the `GET /room/get` or `GET /room/get_by_client_id` endpoints.
</ParamField>

## Response

A successful deletion returns an HTTP `200` status with a `null` body. No additional data is returned.

<RequestExample>

```bash cURL
curl --location 'https://fssportal.com/api/v1/room/delete' \
--header 'platform: WEB' \
--header 'api-key: FSS2023' \
--header 'Authorization: Bearer {your_token}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "room_id": 4945
}'
```

</RequestExample>

<ResponseExample>

```json 200 Success
null
```

```json 401 Unauthorized
{
  "message": "Unauthenticated."
}
```

```json 422 Unprocessable Entity
{
  "message": "The room_id field is required.",
  "errors": {
    "room_id": ["The room_id field is required."]
  }
}
```

```json 404 Not Found
{
  "message": "Room not found."
}
```

</ResponseExample>
