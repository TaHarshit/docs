---
title: "GET /room/get_by_client_id — List Rooms for a Client"
sidebarTitle: "Rooms by Client"
description: "GET /room/get_by_client_id — Returns all rooms for a given client ID, ordered by creation date. Use this before fetching or creating measurements."
---

Use this endpoint to retrieve all rooms belonging to a specific client. You provide the client ID, and the API returns every room created under that client's project, ordered by creation date. This is the primary way to enumerate rooms before fetching measurements or performing updates.

## Endpoint

```
POST https://fssportal.com/api/v1/room/get_by_client_id
```

<Note>
  Although this endpoint retrieves data, it uses the `POST` HTTP method and accepts the client ID in the request body.
</Note>

## Headers

| Header          | Value                  | Required |
|-----------------|------------------------|----------|
| `platform`      | `WEB`                  | Yes      |
| `api-key`       | `FSS2023`              | Yes      |
| `Authorization` | `Bearer {your_token}`  | Yes      |
| `Content-Type`  | `application/json`     | Yes      |

## Request Body

<ParamField body="client_id" type="integer" required>
  The unique ID of the client whose rooms you want to list. You can obtain client IDs from the `POST /client/list` endpoint.
</ParamField>

## Response

<ResponseField name="message" type="string">
  A human-readable status message confirming the result of the request.
</ResponseField>

<ResponseField name="data" type="array">
  An array of room objects associated with the given client, ordered by creation date (most recent last). Each object represents one room.
  <Expandable title="data item">
    <ResponseField name="id" type="integer">
      The unique ID of the room.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the room.
    </ResponseField>
    <ResponseField name="admin_room_id" type="integer">
      The ID of the predefined room type associated with this room, or `null` if none was assigned.
    </ResponseField>
    <ResponseField name="client_id" type="integer">
      The ID of the client this room belongs to.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp indicating when the room was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --location 'https://fssportal.com/api/v1/room/get_by_client_id' \
--header 'platform: WEB' \
--header 'api-key: FSS2023' \
--header 'Authorization: Bearer {your_token}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "client_id": 1856
}'
```

</RequestExample>
