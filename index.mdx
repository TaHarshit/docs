The FSS Measurement API gives field service professionals a complete backend for managing window measurement projects. With this API, you can create and organize clients, record multiple window measurement types, manage rooms within projects, track lead sources, and handle subscriptions — all through a consistent REST interface.

## How it works

<Steps>
  <Step title="Create an account">
    Sign up at [dashboard.fss-measurement.com](https://dashboard.fss-measurement.com) and activate a subscription plan.
  </Step>
  <Step title="Get your API token">
    Sign in via the API to receive a Bearer token, then include it in the `Authorization` header on every protected request.
  </Step>
  <Step title="Add clients and rooms">
    Create client records and organize them into rooms to prepare for measurement data entry.
  </Step>
  <Step title="Record measurements">
    Submit window measurements for each room — single windows, multiple windows, specialty windows, awnings, and more.
  </Step>
</Steps>
