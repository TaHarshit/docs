The FSS Measurement API gives you programmatic access to the full FSS platform — from managing client records and room configurations to capturing window measurements and tracking lead sources. It is designed for developers building custom integrations, mobile applications, and automated workflows on top of FSS Measurement. All interactions follow a consistent REST pattern and return JSON responses.

## Base URL

All API requests target the following base URL:

```
https://fssportal.com/api/v1
```

<Note>
  The interactive API playground only supports HTTPS. For local HTTP testing, use a REST client such as curl, Insomnia, or Postman pointed at your local endpoint.
</Note>

## Response format

Every API response — success or error — returns JSON with a consistent envelope structure.

**Success response**

```json
{
  "status": "success",
  "message": "Operation completed successfully.",
  "data": { }
}
```

**Error response**

```json
{
  "status": "error",
  "message": "A description of what went wrong."
}
```

The `data` field contains the resource or list of resources returned by the endpoint. On error, `data` is omitted and `message` explains the failure.

## Rate limiting

The API allows **60 requests per minute** per user token. Every response includes the following headers so you can track consumption:

| Header | Description |
|---|---|
| `X-RateLimit-Limit` | Maximum number of requests allowed per minute |
| `X-RateLimit-Remaining` | Number of requests remaining in the current window |

When you exceed the limit, the API returns a `429 Too Many Requests` response. Back off and retry after the current window resets.

## Error status codes

| Status code | Meaning |
|---|---|
| `200` | Request succeeded |
| `401` | Unauthorized — missing or invalid Bearer token |
| `403` | Forbidden — valid token but no active subscription |
| `404` | Not found — the requested resource does not exist |
| `422` | Validation error — the request body failed validation |
| `429` | Too many requests — rate limit exceeded |
| `500` | Internal server error — contact support if this persists |

## Versioning

The current stable version is **v1**, reflected in the base URL path `/api/v1`. Future releases will increment the version number (`v2`, `v3`, and so on). Version 1 will remain supported and receive no breaking changes after new versions are released.
